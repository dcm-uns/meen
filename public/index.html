ℹ️ Información

Nota para estudiantes: ¿Por qué la búsqueda siempre devuelve películas con "Toy" en el título, sin importar lo que escribas? Esto es intencional. Busca en el código backend dónde está el filtro hardcodeado y corrígelo.

Estructura de la aplicación:

  • Backend: Express.js + MongoDB
  • Frontend: HTML5 + JavaScript vanilla + CSS
  • API: Endpoints GET /peliculas (búsqueda) y POST /peliculas (agregar)
